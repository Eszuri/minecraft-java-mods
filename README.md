# Reflective Shiel

mod for Minecraft that enhances shield mechanics with full-body protection and damage reflection.

## Features

- **360° Protection**: Blocks attacks from all directions with no blind spots.
- **Melee Reflection**: Reflects 100% of incoming melee damage and knocks back the attacker.

## Installation

1. Install Fabric Loader and Fabric API.
2. Place the mod `.jar` file into your `.minecraft/mods` folder.
