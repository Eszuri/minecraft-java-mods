Easily Critical

A lightweight Fabric mod for configurable Mace smash triggers, standing critical hits, fall damage protection, and zero cooldowns.

Key Features

Combat mechanics and weapon enhancement.

Smash Attack Trigger

Customize the required fall distance to trigger a Mace smash attack: 1.5 blocks (default vanilla), 1.0 block (standard jump), or 0 blocks (standing on the ground without jumping).

Wind Burst Trigger

Customize the activation height for the Wind Burst enchantment: 1.5 blocks (default), 1.0 block, or 0 blocks for immediate burst on hit from the ground.

Easily Critical Damage

Enables critical hits (+50% damage and particles) on all weapons while standing still without jumping. In 0 Blocks mode on Mace, critical hits are automatically replaced by Smash Attacks.

No Cooldown

Removes item cooldowns (Ender Pearl, Chorus Fruit, Shield, Wind Charge) and attack swing delays for instant full-strength hits.

Fall Damage Protection

Grants fall damage immunity specifically when launched into the air by Wind Burst, keeping high-mobility combat safe.

Minimum Smash Bonus

Guarantees a minimum +4.0 smash bonus damage on low-height or 0-block hits, ensuring effective ground combat.

Configuration

Settings are stored in .minecraft/config/easily_critical.json.

Parameter Supported Values Default Description
smashTrigger "BLOCKS_1_5", "BLOCKS_1_0", "BLOCKS_0" "BLOCKS_1_5" Mace smash attack trigger distance.
windBurstTrigger "BLOCKS_1_5", "BLOCKS_1_0", "BLOCKS_0" "BLOCKS_1_5" Wind Burst explosion trigger distance.
fallDamageMace true / false true Fall damage protection when launched by Wind Burst.
easilyCriticalDamage true / false true Critical attack without jumping.
noCooldown true / false true Removes item cooldowns and attack swing delays.
JSON Configuration Example

Edit config/easily_critical.json to configure manually:

{
  "smashTrigger": "BLOCKS_0",
  "windBurstTrigger": "BLOCKS_0",
  "fallDamageMace": true,
  "easilyCriticalDamage": true,
  "noCooldown": true
}

Troubleshooting

Common questions and configuration solutions.

1. Smash attacks not triggering while standing

Cause: The configuration is currently set to the 1.5 blocks vanilla default.

Solution: Open Mod Menu settings and select 0 Blocks, or set "smashTrigger": "BLOCKS_0" in config/easily_critical.json.

2. Fall damage still occurring from high cliff drops

Cause: Fall protection is specialized for upward launches caused by Wind Burst.

Solution: Fall damage immunity protects you when launched into the air by Wind Burst. For ordinary high cliff falls, hit an entity with a Mace smash attack before landing.

3. Attack speed or item delay feels unchanged

Cause: The noCooldown option may be disabled or another mod is overriding weapon attack attributes.

Solution: Ensure noCooldown is set to true in your configuration and restart the game.

4. Mod Menu settings button not appearing in pause menu

Cause: Mod Menu is an optional companion mod for Fabric that provides the in-game GUI.

Solution: Install the Mod Menu mod in your mods/ folder, or configure config/easily_critical.json directly with any text editor.
